# ROS2 rUBot Tutorial

Contains a ROS2 Humble tutorial needed to perform the rUBot project

## Tutorial packages

- `ros2_tutorial`: introductory ROS 2 publisher, subscriber and launch examples.
- `ros2_move_turtle`: Turtlesim pose-control examples using topics and services.
- `turtle_interfaces`: custom service interfaces used by the distributed-control exercises.
- `pose_tf2`: 3D POSE representation with TF2, URDF and RViz2.

The TF2 Exercise 4 instructions are available in
[`Documentation/04_ROS2_TF2_POSE_Exercise4.md`](Documentation/04_ROS2_TF2_POSE_Exercise4.md).
